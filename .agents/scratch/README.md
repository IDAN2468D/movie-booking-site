# 🧪 Agent Scratch & Sandbox Environment

This directory is reserved for transient test scripts, quick verification snippets, and temporary execution logs created by AI Agents.

## Usage Guidelines
1. Name test scripts descriptively (e.g. `test_schema_validation.py`, `check_routes.js`).
2. Keep log outputs brief (under 5 lines) when reporting results to the user.
3. Clean up obsolete scratch files at the end of feature execution cycles.
