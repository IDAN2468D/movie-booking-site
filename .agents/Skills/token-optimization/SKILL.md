# ⚡ Skill: Token Optimization & Context Window Management

## Purpose
Enables AI Agents to execute tasks with maximum speed, precise accuracy, and minimum token consumption.

## Guidelines
1. **Targeted Reading:** Read only necessary line ranges of source code. Avoid dumping large files into context.
2. **Dense Formatting:** Use compact markdown tables and concise bullet points rather than narrative paragraphs.
3. **Context Pruning:** Exclude build artifacts (`.next/`, `node_modules/`, `public/`) from full-text queries.
4. **State Compression:** Keep `.agents/state/task.md` short and checklist-driven. Archive completed sprint logs when needed.
5. **Sandbox Verification:** Execute scripts in `.agents/scratch/` and return 2–3 line summary outputs.
