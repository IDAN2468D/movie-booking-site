# Lighting Bands Specification

## Time Bands Configuration
- `dawn`: 05:00 - 07:59 (Accent: Amber / Peach `#F59E0B`)
- `day`: 08:00 - 17:59 (Accent: Vibrant Gold `#EAB308`)
- `sunset`: 18:00 - 20:59 (Accent: Magenta / Deep Orange `#F97316`)
- `night`: 21:00 - 04:59 (Accent: Electric Cyan `#06B6D4`)
