# מדריך עברי: מסגרת העבודה Agent Stack Framework (v9.5 SDD)

## סקירה כללית

מסגרת העבודה Agent Stack Framework מהווה את מנוע הביצוע המרכזי של אג'נטים בפרויקט CinePulse. המטרה היא ביטול סטיית הקשר (Context Drift), מניעת בזבוז טוקנים והבטחת פיתוח אוטונומי מדויק בשיטת Specification-Driven Development (SDD).

כל משימה ארוכת טווח או הוספת פיצ'ר מחויבת לעבור דרך חמש שכבות הביצוע.

---

## 5 שכבות הביצוע (The 5-Layer Stack)

| שכבה | שם השכבה | ייעוד וכלים | שער בקרה |
| :--- | :--- | :--- | :--- |
| **שכבה 1** | Memory Persistence & Context Pruning | קריאת ועדכון קובצי הסטייט ב-`.agents/state/` | סנכרון אוטומטי של כל 4 הקבצים |
| **שכבה 2** | PRD & Scope Protection | הגדרת גבולות המוצר וסיפורי משתמש (`PRD_TEMPLATE.md`) | מניעת זליגת דרישות (Scope Creep) |
| **שכבה 3** | Spec Technical Blueprint | חוזה נתונים, סכמות Zod, ותקרת 200 שורות קוד | עמידה קפדנית ב-200 LOC לקובץ |
| **שכבה 4** | Plan & Gated Checkpoints | יצירת ארטיפקט `implementation_plan.md` | **שער עצירה קריטי לאישור משתמש** |
| **שכבה 5** | Loop Self-Healing & QA | קומפילציה, לינטר ובדיקות יחידה (`vitest`) | חוק 3 הפסילות (3-Strike Rule) |

---

## עקרונות הליבה של המסגרת

1. **תקרת 200 שורות קוד (200 LOC Ceiling):**
   - כל קובץ שנוצר או נערך חייב להכיל לכל היותר 200 שורות קוד.
   - לוגיקה מורכבת מפוצלת לתת-רכיבים, הוקים ייעודיים (`use*.ts`) או Server Actions.

2. **שער אישור המשתמש (Layer 4 Gate):**
   - האג'נט חייב לעצור תמיד לפני שינויי קוד ממשיים, לפרסם ארטיפקט תוכנית עבודה ולהמתין לאישור מפורש.

3. **חוק 3 הפסילות (3-Strike Rule):**
   - במידה ובדיקה או בנייה נכשלת 3 פעמים רצופות על אותה שגיאה, על האג'נט לעצור, לתעד את התקלה ב-`latest.md` ולבקש התערבות.

4. **סנכרון 4 קובצי הסטייט:**
   - בכל סיום ספרינט או פיצ'ר, חובה לעדכן את:
     - `.agents/state/task.md`
     - `.agents/state/latest.md`
     - `.agents/state/ARCHITECTURE_STATE.md`
     - `.agents/state/SPRINTS.md`
