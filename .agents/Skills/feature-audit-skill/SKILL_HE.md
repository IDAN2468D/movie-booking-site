# מדריך עברי: מנוע ביקורת פיצ'רים ומפת דרכים (v9.5 SDD)

## סקירה כללית

סקיל זה משמש לביצוע ביקורת ארכיטקטונית וטכנולוגית מעמיקה על היכולות הקיימות בפרויקט CinePulse, זיהוי פערים (Gap Analysis) וגיבוש מפת דרכים מדויקת לשדרוג ספרינטים עתידיים.

הסקיל פועל בסנכרון מלא עם מסגרת העבודה Agent Stack Framework ועקרונות Liquid Glass 4.0, 120Hz GPU ו-Web Audio API.

---

## פרוטוקול הביצוע ב-4 שלבים

### 1. טעינת הקשר (Context Loading)
- קריאת קובץ הסטייט הראשי: `.agents/state/ARCHITECTURE_STATE.md`.
- סקירת הספרינטים האחרונים ב-`.agents/state/SPRINTS.md`.
- טעינת תבניות ה-PRD וה-Spec מ-`.agents/templates/`.

### 2. ניתוח פערים מעמיק (Gap Analysis)
- השוואת פיצ'רים קיימים מול סטנדרטים עדכניים של חוויית קולנוע היברידית בישראל (הזמנה קבוצתית, תגיות כשרות, מע"מ 18%, לוקליזציה עברית מלאה).
- איתור שכבות חסרות מבלי ליצור עומס או כפילויות במערכת (Lean Architecture).

### 3. בדיקת היתכנות טכנית (Feasibility Check)
- ויזואליה: תמיכה ב-120Hz Zero-Reflow GPU.
- שמע: שילוב Web Audio API ומשוב הפטי.
- אבטחה: אפס חשיפת נתוני MongoDB ללקוח ואימות Zod קפדני.
- בידוד קבצים: תקרת 200 שורות קוד לכל קובץ.

### 4. הפקת מפת דרכים (Roadmap Generation)
- בניית טבלת שדרוגים ממוקדת:
  - שם הפיצ'ר
  - ספרינט היעד
  - מוכנות PRD / SPEC
  - ממשקים ורכיבים מושפעים
